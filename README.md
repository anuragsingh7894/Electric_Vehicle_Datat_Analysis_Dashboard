# Electric_Vehicle_Datat_Analysis_Dashboard
🚗 Electric Vehicle Data Analysis Dashboard | Tableau
📌 Project Overview

This project presents an interactive Electric Vehicle (EV) Data Analysis Dashboard built using Tableau. The dashboard analyzes over 150,000+ electric vehicle registrations to uncover trends in EV adoption, manufacturer market share, vehicle types, electric range, and regional distribution.

The objective of this project is to transform raw EV registration data into meaningful business insights using data visualization and storytelling.

🎯 Objectives
Analyze the growth of Electric Vehicles over time.
Compare Battery Electric Vehicles (BEVs) and Plug-in Hybrid Electric Vehicles (PHEVs).
Identify leading manufacturers and popular EV models.
Explore electric range distribution.
Analyze EV adoption across different states.
Evaluate CAFV eligibility distribution.

🔍 Key Insights
Over 150,000 electric vehicles are included in the dataset.
Battery Electric Vehicles (BEVs) account for approximately 77% of all registrations, showing a strong preference for fully electric vehicles.
Tesla dominates the market with more than 50% of registered EVs.
EV registrations have grown consistently since 2017, reaching their highest level in 2023.
Washington has the highest concentration of registered electric vehicles.
Most registered vehicles fall within the 0–50 km electric range, indicating a mix of earlier-generation EVs and plug-in hybrids.
A significant portion of vehicles have unknown CAFV eligibility, highlighting opportunities for improving data quality.
